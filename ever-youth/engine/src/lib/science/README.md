# Происхождение научной сцены

Перенесено по просьбе владельца 09.11.2026 из локального проекта:
`C:/ITVM/sites/itvm-institute-prototype/src/science-scene.ts`.

Сохранены процедурная ДНК, везикулы, частицы, движущийся фон, параллакс и переходы глав. Обвязка, навигация и контакты адаптированы к текущему Astro-сайту. По уточнению владельца восстановлена исходная тёмная палитра. Статичная схема взята из `public/science-fallback.svg` того же проекта.

Полная статья и описания трёх глав восстановлены из `C:/ITVM/sites/itvm-science-content.tar.gz`, `dist/exovesicles/index.html`. Текст статьи хранится в `src/content/exovesicles-evidence.html`; убрана только устаревшая дата редакции. Ссылки на исследования и FAQ сохранены.
