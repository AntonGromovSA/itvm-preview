# Происхождение научной сцены

Перенесено по просьбе владельца 09.11.2026 из локального проекта:
`C:/ITVM/sites/itvm-institute-prototype/src/science-scene.ts`.

Сохранены процедурная ДНК, везикулы, частицы, движущийся фон, параллакс и переходы глав. Обвязка, светлая палитра отображения, навигация и контакты адаптированы к текущему Astro-сайту. Статичная схема взята из `public/science-fallback.svg` того же проекта.

Терминология страницы сверена с MISEV2023: https://doi.org/10.1002/jev2.12404. Страница описывает научную тему; новые цены и клинические обещания не добавлены.
