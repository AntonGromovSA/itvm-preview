# ИТВМ — самостоятельный сайт на Astro

Светлая многостраничная версия без Tilda: собственные Astro-компоненты, TypeScript, нативные HTML/CSS и небольшой JavaScript для меню, поиска и фильтров. React/Three.js используются только для отдельно добавляемых 3D-блоков. На Spaceweb работает статическая сборка; постоянный Node.js-сервер и база данных не нужны.

Production: https://itvm.ru/ever-youth/index.html. Корень itvm.ru **не переключать без отдельной отмашки владельца**.

## Источники и правки

- `src/data/prices.json` — единый прайс: 1760 позиций, 14 разделов. Главный источник — XLS от 05.10.2026. `sourceRow` — устойчивый идентификатор связи с услугами врача. `null` означает «Стоимость уточняйте».
- `src/data/clinic.json` — телефоны, адрес, WhatsApp и VK.
- `src/data/doctors.json` — 40 отдельных профилей текущего сайта, имена, роли, фотографии и ссылки. Исходная таблица врачей дополнена ранее опубликованными профилями института. Не использовать старые цены из примечаний таблицы врачей.
- `src/data/pages/*.json` — маршруты, метаданные, поисковые данные и связи с прайсом. Для 85 страниц отображаемая композиция находится в `src/compositions/`, а не в плоском массиве разделов. `priceRows` профиля содержит идентификаторы позиций общего прайса.
- `src/data/visuals.json` — фотографии главной.
- `src/components/Header.astro`, `Footer.astro` — единые шапка и подвал.
- `OriginalCover.astro` — исходное фоновое видео главной; `AuthoredPage.astro` — сохранённые авторские композиции и собственный JavaScript слайдеров/вкладок; `PriceList.astro` — единый актуальный прайс. `ContentPage.astro` обслуживает страницы без авторской композиции.
- `src/compositions/`, `public/composition/`, `public/design-media/` — сохранённая структура исходного сайта, изолированные CSS и оригинальная инфографика. `src/styles/authored.css` задаёт светлую тему и адаптацию. `public/brand/crest.png` — оригинальный герб без перерисовки.
- `src/styles/clinic.css` — светлая тема, адаптация, шрифты и интерактивные состояния. Локальные шрифты WOFF2 находятся в `src/assets/fonts/`.
- `public/media/` — WebP с несколькими размерами. В каждом объекте изображения указаны `src`, `srcset`, `width`, `height`, `alt`. `public/video/` — исходные видео.

Визуальной админки пока нет. Не заменять существующие авторские композиции универсальной текстовой раскладкой. Не менять герб, фотографии, инфографику и видео без запроса владельца. Смена тёмного фона на светлый не означает разрешение на редизайн. При правке существующей страницы редактируйте её HTML в `src/compositions/` и соответствующие CSS. Цены в таблицах профилей подставляются из `prices.json` при сборке.

`scripts/restore-authored-design.py` однократно переносит согласованный снимок `../site`: сохраняет группы и расположение, меняет цвета, удаляет редакторские скрипты и создаёт статические ресурсы. Повторный запуск перезаписывает композиции, поэтому сначала сохраняйте ручные правки. Для него нужны Python, BeautifulSoup и tinycss2. Компонент `HomePage.astro` прежней упрощённой версии не используется в маршрутах.

## Запуск и проверка

Node >=22.23.4, pnpm. Версии зафиксированы lock-файлом; совместимая версия `@emnapi/runtime` закреплена в `pnpm-workspace.yaml`.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm build
pnpm verify
python scripts/local-preview.py --directory dist --port 8766
```

Локальный статический просмотр: http://127.0.0.1:8766/ever-youth/index.html. Astro dev/preview может показывать страницы по адресам без `.html`; на Spaceweb сохранены все старые `.html`-адреса.

`pnpm verify` проверяет 120 маршрутов, отсутствие Tilda в HTML/CSS/JS, цены, биографии, исходные группы и блоки композиции, точное совпадение герба, наличие фонового видео, поиск, уникальные ID и ресурсы HTML/CSS. Эталон `../site` — исходный согласованный снимок. Проверки сборки дополнять визуальной проверкой в браузере на компьютере и телефоне.

## Новые блоки

Обычный раздел в массиве `sections`:

```json
{"id":"preparation","title":"Подготовка к визиту","html":"<p>Согласованный текст клиники.</p>","images":[],"links":[],"videos":[]}
```

В этот раздел можно добавить `slides`:

```json
"slides":[{"image":"media/room-1.webp","alt":"Кабинет врача","title":"Кабинет"},{"image":"media/room-2.webp","alt":"Холл клиники","title":"Холл"}]
```

Или `model`:

```json
"model":{"src":"models/anatomy.glb","poster":"media/anatomy.webp","label":"Анатомическая модель"}
```

Слайдер поддерживает кнопки, клавиатуру и reduced motion. 3D загружается при появлении блока; обязательный для реальной страницы постер остаётся при недоступности WebGL. Саму модель положите в `public/models/`. React/Three.js не загружаются на страницах без модели. Новые компоненты проверяются отдельно через `CLINIC_COMPONENT_LAB=1`; папка `dist-lab` не публикуется.

Фоновое видео главной запускается без звука с возможностью паузы; исходная анимированная инфографика использует нативный video. Запись остаётся через телефон и WhatsApp; отправка заявок в CRM/почту не имитируется.

## Публикация и резервная копия

После успешных проверок:

```sh
python scripts/package-release.py
```

`releases/native-light-20261108.zip` содержит **полную** чистую сборку. Загрузить содержимое только в `public_html/ever-youth/` на Spaceweb. Для исключения остатков старых файлов подготовить новую папку, распаковать архив, сохранить прежнюю папку для отката и заменить её новой. Корневой `.htaccess`, основной сайт, WordPress и DNS не менять.

`src`, `node_modules`, `.git`, XLS/CSV, `reports` и исходные учётные данные не публиковать. Подробные отчёты остаются локально и игнорируются Git. `verify-live.py` сравнивает файлы опубликованной версии с манифестом сборки.

Предыдущая совместимая миграция сохранена в Git-коммите `f1878ff`; исходный HTML-снимок — `../site`. Старые блоки и файлы Tilda вынесены из активного движка в локальный архив `ever-youth/retired-engine-20261108`. Они не нужны для сборки или работы нового сайта.
