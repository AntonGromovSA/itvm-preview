# Движок сайта ИТВМ

Astro 7, TypeScript, React islands и Three.js. Сборка выдаёт обычные HTML/CSS/JS для Spaceweb: Node.js на сервере не нужен. Рабочий адрес — https://itvm.ru/ever-youth/index.html. Корень itvm.ru переключается только по отдельному разрешению владельца.

## Что перенесено

120 исходных HTML-маршрутов (включая 32 перехода и 404), изображения, видео, контакты, прайс и существующая верстка. Шапка и подвал теперь общие компоненты. 881 текстовое поле вынесено в JSON. Поиск и прайс генерируются при сборке.

Это совместимая миграция: сложные Tilda-блоки и их браузерные скрипты сохранены для точного воспроизведения оформления. Они больше не требуют экспорта из Tilda; постепенно их можно заменять компонентами Astro. Визуальной панели администратора пока нет. React и Three.js загружаются на страницах, где добавлен соответствующий компонент.

## Где редактировать

- `src/data/prices.json` — единственный актуальный прайс. Приоритет: XLS от 05.10.2026. `sourceRow` связывает позицию с таблицами на страницах специалистов; не менять без переноса связей. `null` означает «Стоимость уточняйте».
- `src/data/clinic.json` — телефоны, WhatsApp и VK, подставляемые в общие блоки и тексты. Адрес и название также сохранены для справки; их вхождения в старых блоках ещё редактируются в текстах/HTML.
- `src/content/texts/ИМЯ.html.json` — текстовые поля конкретной страницы. Значения содержат допустимую HTML-разметку. Ключи соответствуют исходным полям Tilda.
- `src/content/pages/ИМЯ.html.json` — название для поиска, атрибуты и порядок блоков страницы. HTML title и SEO-поля находятся в указанном здесь `headFile`.
- `src/content/blocks/` — сохранённые блоки с изображениями, видео и сложной версткой; часть текстов вне Zero Block редактируется здесь.
- `src/content/shared/` — единые шаблоны шапки и подвала.
- `src/data/specialists.json` — исходная таблица специалистов для справки, **не** автоматический источник всех карточек. Биографии редактируются в текстах/блоках страниц; цены берутся из `prices.json`. Старые цены из примечаний таблицы врачей не использовать.
- `public/assets/` — изображения, видео, шрифты и будущие `.glb/.gltf` модели.

## Запуск и публикация

Нужен Node >=22.23.4 и pnpm. Совместимый `@emnapi/runtime` закреплён в `pnpm-workspace.yaml`, чтобы проверка Astro не использовала несовместимую beta-зависимость.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm build
pnpm verify
python scripts/package-release.py
pnpm preview
```

Для точного просмотра старых `.html`-адресов на обычном статическом сервере: `python scripts/local-preview.py --directory dist --port 8766`, затем `/ever-youth/index.html`. Astro preview может маршрутизировать сгенерированные страницы по адресам без `.html`; на Spaceweb сохранены именно старые адреса с расширением.

`verify` сравнивает миграцию с `../site`: тексты без форматирующих пробелов, ссылки, медиа, порядок записей, 1760 цен, локальные ресурсы и индекс поиска. При согласованной редактуре содержания обновите эталон осознанно; не ослабляйте проверку ради прохождения.

Загружать **только содержимое `dist/` в существующий `public_html/ever-youth/`**. `node_modules`, `src`, исходные XLS/CSV, отчёты, `.git` и учётные данные не публиковать. Архив в `releases/` содержит только изменившиеся относительно `../site` файлы. Перед загрузкой сохранить резервную копию текущей папки. Корневой `.htaccess`, WordPress и DNS не менять. Секретов в проекте движка нет.

`scripts/import_legacy.py` — одноразовый импорт исходного снимка, **не запускать после ручных правок**, он перезапишет JSON/блоки. Обычная сборка его не вызывает.

После изменения JSON/HTML в `src/content` перезапустите dev-сервер или выполните сборку: совместимые фрагменты читаются из файлов при запуске, горячая замена для них пока не настроена.

## Новые слайды и 3D

В массив `blocks` нужной страницы перед подвалом добавляется независимый блок:

```json
{"kind":"slides","id":"clinic-tour","label":"Интерьеры клиники","slides":[{"image":"assets/room-1.jpg","alt":"Кабинет врача","title":"Кабинет"},{"image":"assets/room-2.jpg","alt":"Холл клиники","title":"Холл"}]}
```

```json
{"kind":"model","id":"anatomy","label":"Анатомическая модель","src":"assets/anatomy.glb","poster":"assets/anatomy-preview.jpg"}
```

Слайдер поддерживает кнопки, клавиатуру, прокрутку и reduced motion. Просмотрщик 3D поддерживает вращение и масштаб, загружается при появлении блока; без WebGL остаётся постер и пояснение. Для реальных страниц указывайте постер и содержательную подпись. Новые блоки не добавлялись в текущий дизайн автоматически.

Изолированная проверка: задайте `CLINIC_COMPONENT_LAB=1`, выполните `pnpm build`, затем `python scripts/local-preview.py --directory dist-lab --port 8767`. Адрес `/ever-youth/component-tests/interactive.html`. Тестовый glTF следует положить в `dist-lab/component-lab.gltf`. В production лаборатория не генерируется; `dist-lab` не публикуется.

Запись по-прежнему через телефон и WhatsApp. Отправка заявок в CRM/почту не настроена и не имитируется.
